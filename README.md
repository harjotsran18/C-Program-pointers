# C Program Pointers

A collection of C programming practice exercises and examples focused on pointers, pointer arithmetic, string manipulation, and arrays.

## Programs Included

- **`palinpnt.c`**: Palindrome checking using pointers.
- **`pntsent.c`**: Character counting and frequency analysis in a sentence using pointers.
- **`pntstr.c`**: String traversal and character printing using pointer iteration.
- **`point.c`**: Introduction to pointers, memory addresses (`&`), dereferencing (`*`), and basic pointer arithmetic.
- **`pointloop.c`**: Iterating through an array using pointer offset notation `*(p + i)`.
- **`pointr.c`**: Array of pointers and dereferencing pointer variables.
- **`pointswap.c`**: Pointer array initialization practice.
- **`whilepnt.c`**: String length calculation and character display using a `while` loop and pointers.

## Compilation & Execution

Compile any program using GCC:
```bash
gcc filename.c -o filename.exe
./filename.exe
```
